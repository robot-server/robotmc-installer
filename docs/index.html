마인크래프트에서 서버에 접속하는 데 필요한 파일을 설치하거나 제거하는 프로그램이에요.

다운로드

최신 버전을 확인하는 중이에요.

  • Windows 최신 릴리스

    서명이 없어서 스마트 앱 컨트롤(SAC)이 켜져 있으면 실행이 막힐 수 있어요.
    Windows 보안의 앱 & 브라우저 컨트롤에서 스마트 앱 컨트롤을 꺼 주세요.
    꺼도 Windows의 PC 보호가 뜨면 추가 정보를 누른 뒤 실행해 주세요.

  • Universal 최신 릴리스

    Java 25 JRE가 필요해요. 없으면 Eclipse Temurin JRE를 설치해 주세요.
    받은 폴더에서 이 명령으로 실행해요.
    실행 명령을 확인하는 중이에요.

설치기가 하는 일

  • 설치

    서버에 접속하는 데 필요한 파일을 설치해요.

  • 제거

    설치한 파일을 다시 뺄 수 있어요.
    세이브는 그대로 둬요.

  • 받는 파일

    Windows는 실행 파일로 받아요.
    Universal은 Windows, macOS, Linux에서 쓸 수 있어요.
